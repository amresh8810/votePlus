# components/

Reusable UI components used across multiple pages.

## Planned components (Phase 4+)

| File | Purpose |
|------|---------|
| `PollCard.jsx` | Displays a poll summary in a list |
| `OptionBar.jsx` | Horizontal bar showing a vote option + live percentage |
| `ResultsChart.jsx` | Live-updating chart (e.g. bar chart via Recharts) |
| `Navbar.jsx` | Top navigation bar with auth state |
| `ProtectedRoute.jsx` | Wraps routes that require authentication |
| `LoadingSpinner.jsx` | Generic loading indicator |

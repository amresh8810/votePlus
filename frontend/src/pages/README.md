# pages/

Route-level components — one file per page/view.

## Planned pages (Phase 4+)

| File | Route | Purpose |
|------|-------|---------|
| `HomePage.jsx` | `/` | Landing page with call-to-action |
| `LoginPage.jsx` | `/login` | User login form |
| `RegisterPage.jsx` | `/register` | User registration form |
| `DashboardPage.jsx` | `/dashboard` | Authenticated user's list of polls |
| `CreatePollPage.jsx` | `/polls/new` | Create a new poll form |
| `PollPage.jsx` | `/polls/:id` | Public voting page for audiences |
| `ResultsPage.jsx` | `/polls/:id/results` | Live results view with chart |
| `NotFoundPage.jsx` | `*` | 404 page |
